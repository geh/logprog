# Propositional Logic

*Logical Programming --- Part 1*

## 1. Logic and computation

Logic originated as part of philosophy. It played a fundamental role in
the development of computing, including Turing machines and logic
circuits.

Today, the relationship goes in both directions:

-   Computing contributes to logic by automating reasoning.
-   Logic contributes to computing by helping us build correct software.

## 2. Propositional logic: syntax

The language of propositional logic (PL) is simple.

  Symbol category         Examples
  ----------------------- --------------------------------
  Propositional symbols   `p`, `q`, `r`, `p1`, `p2`, ...
  Logical symbols         `!`, `|`, `&`
  Punctuation             `(`, `)`

Here `!` means NOT, `|` means OR, and `&` means AND.

### Formation rules

1.  Every propositional symbol `p` is a formula.
2.  If `phi` and `psi` are formulas, then `!phi`, `(phi | psi)`, and
    `(phi & psi)` are formulas.
3.  Nothing else is a formula of PL.

## 3. Propositional logic: semantics

A formula is interpreted in a particular situation, called a *model*.
The nature of a model depends on the logical language.

A PL model is an interpretation `I` mapping each propositional symbol to
`0` (false) or `1` (true). For example:

``` text
I(p) = 0
I(q) = 1
```

The truth value of a formula depends only on the truth values assigned
to its propositional symbols and on the formula's structure. The same
formula can therefore have different truth values under different
interpretations.

### Meaning of the logical operators

  Formula       True when                              False when
  ------------- -------------------------------------- -----------------------
  `!phi`        `phi` is false                         `phi` is true
  `phi | psi`   At least one of `phi`, `psi` is true   Both are false
  `phi & psi`   Both `phi`, `psi` are true             At least one is false

## 4. A diplomatic problem

Imagine that you are in charge of protocol for an embassy ball.

-   The Prince instructs you to invite Peru or exclude Qatar.
-   The Queen asks you to invite Qatar, or Romania, or both.
-   The King, in a bad mood, wants to snub Romania, Peru, or both.

**Question:** Who should you invite?

Questions to consider:

-   Can this problem be modeled using propositional logic?
-   What do we gain by doing so?
-   What questions can we ask of the resulting model?

## 5. Formalizing the diplomatic problem

Use three propositional symbols:

  Symbol   Meaning          Negation
  -------- ---------------- -----------------------
  `P`      Invite Peru      `!P`: exclude Peru
  `Q`      Invite Qatar     `!Q`: exclude Qatar
  `R`      Invite Romania   `!R`: exclude Romania

The three requirements are:

  Person   Requirement   Meaning
  -------- ------------- ----------------------------------
  Prince   `P | !Q`      Invite Peru or exclude Qatar
  Queen    `Q | R`       Invite Qatar or Romania, or both
  King     `!R | !P`     Snub Romania or Peru, or both

The complete formula is:

``` text
F = (P | !Q) & (Q | R) & (!R | !P)
```

## 6. Analyzing the diplomatic problem

From the Prince's and Queen's requirements:

``` text
P | !Q       Prince
Q | R        Queen
-------------------
P | R
```

Thus, `F` implies `P | R`: if `F` is true, then `P | R` must also be
true. Satisfying the Prince and Queen requires inviting Peru or Romania,
or both.

## 7. Solving the diplomatic problem

Exactly two interpretations satisfy `F`:

  Interpretation     `P`   `Q`   `R` Invitations
  ---------------- ----- ----- ----- ---------------------
  `I1`                 1     1     0 Peru and Qatar only
  `I2`                 0     0     1 Romania only

## 8. Beyond diplomacy

Propositional logic is expressive enough to model many kinds of
problems, including:

-   Graph coloring.
-   Constraint-satisfaction problems, such as Sudoku.
-   Hardware problems.
-   Planning tasks that move a system from state A to state B.

## 9. Application: graph coloring

Given a graph `G = (N, E)`, where `N` is a set of nodes and `E` is a set
of edges, and a fixed number `k` of colors, determine whether colors can
be assigned so that:

1.  Every node has exactly one color.
2.  For every edge `(i, j)` in `E`, nodes `i` and `j` have different
    colors.

A graph can be sketched using ASCII:

``` text
  (1)----->(2)
   ^        |
   |        v
  (3)<-----(4)
```

The sketch is illustrative; the formal encoding below applies to any
graph.

## 10. Graph-coloring encoding

Let `n` be the number of nodes and `k` the number of colors. Use `n * k`
propositional symbols:

``` text
p_ij = "node i has color j"
```

The formula must enforce three conditions.

### 1. Every node has at least one color

For each node `i`, where `1 <= i <= n`:

``` text
p_i1 | p_i2 | ... | p_ik
```

### 2. Every node has at most one color

For every node `i` and every pair of colors `l < m`:

``` text
!p_il | !p_im
```

### 3. Adjacent nodes have different colors

For each edge `(i, j)` in `E` and each color `l`:

``` text
!p_il | !p_jl
```

The complete formula `F` is the conjunction of all subformulas generated
by these rules.

## 11. Exercise: graph coloring with two colors
